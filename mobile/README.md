# FirePredict Mobile App

FirePredict is available as a compiled Android APK. The mobile app source code is proprietary and not included in this repository.

## Download the App

**Download the latest APK from the [Releases page](../../releases).**

Requirements:
- Android 6.0 (API 23) or higher
- ~15 MB storage space

## Installation

1. Download `FirePredict_app.apk` from the Releases page
2. On your Android phone, open the downloaded file
3. If prompted, allow **"Install from unknown sources"** in your phone settings
4. Tap **Install**

## Features

- **Impact Dashboard** — fire statistics for Mount Kilimanjaro (2015–2025)
- **Real-Time Alerts** — zone-level fire risk alerts with predicted windows and recommended actions
- **Interactive Risk Map** — colour-coded zones from Very Low (green) to High (red)
- **Weather Dashboard** — temperature, humidity, wind speed, rainfall with fire risk indicators
- **Community Fire Reporting** — GPS-tagged photo reports sent to forest managers
- **Offline Mode** — works without internet using cached data

## Connecting to the Backend

By default the app works in offline demo mode. To connect to a live FirePredict backend:

1. Set up the backend server (see [`../backend/`](../backend/))
2. Contact Dr. Cesilia Mambile for the trained model weights
3. Configure your server IP in the app settings
